# 🏃‍♂️ Associação Atlética de Manaus (AAM) - Plataforma de Corridas

Uma landing page interativa desenvolvida para a divulgação de maratonas e eventos esportivos promovidos por uma associação atlética fictícia. O projeto visa centralizar informações de percursos, inscrições e engajamento da comunidade esportiva na capital amazonense.

## ✨ Funcionalidades em Destaque

- **Cronômetro Regressivo (Countdown):** Lógica customizada em JavaScript para contagem regressiva em tempo real até a data do próximo grande evento esportivo.
- **Catálogo de Percursos:** Seção dedicada à exibição das diferentes modalidades de corrida, segmentadas por quilometragem (KMs) para atender de corredores iniciantes a maratonistas experientes.
- **Design Temático e Regional:** Interface visual imersiva que destaca cartões postais e a cultura de corrida de rua em Manaus.

> **⚠️ Nota Técnica sobre o Backend:** 
> Originalmente, este projeto possuía integração com um banco de dados relacional para gerenciar o formulário de inscrições dos atletas. Para fins de demonstração neste portfólio, a aplicação foi adaptada para operar como uma interface estática (Front-end Demo), focando na apresentação visual e no funcionamento dos scripts do lado do cliente (JavaScript).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica das seções de eventos e navegação.
- **CSS3:** Estilização, paleta de cores institucional e responsividade.
- **JavaScript (Vanilla):** Manipulação do DOM e engenharia do cronômetro dinâmico.
